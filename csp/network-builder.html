Words to know
Computing device
A physical machine that can run a program: a laptop, phone, server or router.
Computer network
A group of connected computing devices that can send and receive data.
Path
The chain of connected devices a message travels through from sender to receiver.
Routing
Choosing which path a message takes.
Hop
One trip across one cable. A → B → C is 2 hops.
Bandwidth
The most data a connection can carry in a set amount of time, measured in bits per second (Mbps = millions of bits per second).

Slow cable: 10 Mbps Fast cable: 100 Mbps Each hop also adds 0.5 s for the computer to forward the message
