Creative Task 1: Intro to Graphics

AP Computer Science Principles · CMU CS Academy, Unit 1

The task

Design and code a picture of your choice using only what you learned in Unit 1. It can be a scene from nature, a place you love, a poster, a logo for a made-up team, a character you invent, or anything else you can draw with shapes. Pick something that matters to you.

This is a still picture. Clicking, moving, and animation come in later units, so your program doesn't need to respond to the user yet.

This task is a practice run for the AP Create Performance Task. You'll plan, build, test, and then explain your code in writing, like you will on the real one.

Your Unit 1 toolbox

Use only these tools. If you find something online that isn't on this list, save the idea for a future creative task.

Canvas

  • 400 × 400 canvas, (0, 0) in the top-left corner
  • x grows to the right, y grows down
  • app.background

Shapes

  • Rect, Oval, Circle
  • Line, Polygon
  • RegularPolygon, Star
  • Label (text)

Colors and style

  • fill: color names, rgb(…), gradient(…)
  • border, borderWidth, dashes
  • opacity
  • Label size

Program structure

  • Code runs top to bottom
  • Later shapes are drawn on top of earlier ones
  • # comments to label parts of your code

Program requirements

Check each one off before you turn in your project.

  • The program runs with no errors in the console.
  • It uses at least 3 different kinds of shapes from the toolbox.
  • It includes at least one Label (a title, a sign, a caption, or other text).
  • It uses at least 2 style properties besides fill, such as border, borderWidth, dashes, opacity, or a gradient.
  • It uses layering on purpose: at least one shape is drawn on top of another because of the order of your code.
  • Everything important is visible on the canvas. Nothing you meant to show is hidden or drawn off the edge.
  • The code has comments that label each part of the picture (for example, # sky, # house, # title).

Plan it first

Before you start coding, fill out the Design and Development Guide:

  1. Description: What will your picture show? Don't worry yet about how to code it.
  2. Canvas sketch: Sketch it on a 400 × 400 grid and label the coordinates of the main shapes.
  3. Code design: For each shape or property you plan to use, write its purpose. For example, Polygon: mountains or opacity: see-through clouds.

Written responses

Answer these after your program is finished. Each one has a tag that shows which AP Create Performance Task skill it practices.

  1. Purpose and audienceAP: Program Design & Purpose
    Who is your picture for, or who would enjoy it? Describe one way your design choices (colors, layout, text, and so on) fit that person or purpose.
  2. Difficulties and opportunitiesAP: Development & Iteration
    Describe one difficulty you ran into, or one opportunity you found to add something you hadn't planned. How did you resolve it or add it? How did your design change from your original plan?
  3. Errors and testingAP: Errors & Testing
    Pick one line of your code. Describe a small change to that line that would cause an error, or would make the picture come out wrong. Explain why it would happen. (Examples: a missing comma or parenthesis, a misspelled shape name, a coordinate that puts a shape off the canvas.)
  4. Order mattersAP: Algorithms (Sequencing)
    Find two lines of code where the order changes what you see. Give the line numbers and describe exactly how the picture would look different if those two lines were swapped.
  5. Code outlineAP: Code explanation
    Fill in a table like the one below with the important coding concepts in your program. Include at least two Unit 1 concepts. Put a star next to the part you're most proud of.

    What would you do differently if you started over, or add if you had more time?
